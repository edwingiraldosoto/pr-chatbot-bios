# Asistente de mesa de ayuda con RAG en Telegram

Asistente conversacional en Telegram que responde preguntas sobre políticas internas
(vacaciones, reembolso de gastos, soporte de TI, trabajo remoto, etc.) basándose
exclusivamente en los documentos de la carpeta `knowledge_base/`, mediante
Retrieval-Augmented Generation (RAG).

> **Estado:** en desarrollo. El proyecto sigue Spec Driven Development: la especificación
> en `specs/` se escribe y se versiona antes que el código. Las instrucciones completas de
> instalación, configuración y uso se agregarán a este archivo al terminar la implementación.

## Mapa de la documentación

| Archivo | Contenido |
|---|---|
| `specs/spec.md` | Qué hace el sistema, requisitos y criterios de aceptación |
| `specs/plan.md` | Cómo se construye: arquitectura, componentes y flujos |
| `specs/tasks.md` | Desglose en tareas trazables a los requisitos |
| `docs/` | Arquitectura, decisiones, uso de IA, evaluación y criterio técnico |
